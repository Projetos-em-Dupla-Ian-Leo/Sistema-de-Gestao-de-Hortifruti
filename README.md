# Sistema-de-Gestao-de-Hortifruti
Este projeto tem como objetivo desenvolver um sistema web de gestão para a Shizen Orgânicos, substituindo processos manuais por uma solução digital integrada, simples e eficiente. A equipe busca otimizar o controle de estoque, pedidos e precificação, garantindo maior organização, redução de erros e agilidade nas operações do dia a dia.
